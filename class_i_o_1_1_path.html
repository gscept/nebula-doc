IO::Path Class Reference

#include <path.h>

Detailed Description

A path is an abstraction around file paths.

It encapsulates the folder path, an optional file name and accompanying file type.

A path lives entirely within Nebulas file system, meaning all paths are relative to content folders, either in 'work' or 'export'.
