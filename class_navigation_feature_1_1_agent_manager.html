NavigationFeature::AgentManager Class Reference

#include <agentmanager.h>

Detailed Description

Moves the entities with a NavAgent component over the navmeshes of the level.

Every loaded navmesh which has agents gets a Detour crowd, which steers its agents along their paths and around each other. An agent joins the crowd of the navmesh baked for its agent kind as soon as that navmesh is loaded, a target set before that is walked to once it has joined.

Each frame the crowd is stepped and the entity is moved:

  • with a Game::Velocity component, the velocity is set and whatever moves the entity by it does, like a physics character controller. The crowd follows the entity, so collisions are respected
  • without one, the position is set to the position on the navmesh

A crowd is made for the agents of its kind there are, with room to spare. When more join than fit, it is made again for all of them, and its agents join again keeping their targets.

The crowds step in jobs, off the game thread. The update starts in OnFrame, joining agents, following their entities and handing out paths, and dispatches a job for every crowd. It finishes in OnEndFrame, before the physics frame, waiting for the jobs and moving the entities. In between the crowds belong to the jobs: a target set meanwhile is put on the navmesh right away and handed to the crowd with the next update, and anything which changes or frees a crowd waits for the jobs first.

A crowd keeps pointers into its navmesh, it is rebuilt when the navmesh is reloaded, and its agents join again, keeping their targets.
