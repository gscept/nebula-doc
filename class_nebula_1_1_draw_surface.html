Nebula.DrawSurface Class Reference

Detailed Description

The ImGui calls the property inspector draws through.

ImGui has one context, and it is the editor's. A managed drawing library allocates its own, so the managed side cannot draw with an ImGui of its own and goes through these instead.

These are only reachable from inside the editor's draw, which is what keeps a build with no editor from ever calling them.

A row is the key in column 0 and one widget in column 1. The widget answers with true when the value changed, and the value it worked on comes back through the buffer the caller gave, because the surface owns no memory the managed side can read afterwards.

bool Nebula.DrawSurface.RowMarker ( string key,
bool authored,
string tip )
inlinestatic

The override marker on a row, drawn after the widget the row's value column has.

It is only drawn when the caller says the row is the instance's own, and the answer is true when it was pressed. What a press means is not this side's decision: it only says which row it was on.
