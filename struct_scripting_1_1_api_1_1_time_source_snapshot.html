Scripting::Api::TimeSourceSnapshot Struct Reference

Detailed Description

The layout the managed time source mirror is built from.

The eight byte fields come first and then the four byte ones, which is the order C# declares as well and the only order that puts the entry at 64 bytes without padding on either side. Ticks and the time factor are widened here, because Timing::Tick is 32 bit and a source that runs long enough wraps.
