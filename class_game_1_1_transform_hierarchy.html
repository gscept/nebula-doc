Game::TransformHierarchy Class Reference

#include <transformhierarchy.h>

Detailed Description

The parent, child and sibling links of the entities in one world's hierarchy.

The hierarchy is the index of which entity is below which. The transforms are not stored here: the local transform is the Game::HTransform component and the world transform is Game::Position, Game::Orientation and Game::Scale, which is what every consumer reads through the query buffers.

An instance is an entity which has a local transform, or an entity which is the parent of one, because a world transform written on a parent has to reach the entities below it.

A write which goes through Game::World::SetComponent is computed at the time it happens, and it propagates to the instances below it, so a transform read after a write is the transform which was written. Propagation goes one way only, towards the leaves.

IsInHierarchy() is the test a transform writer makes before it does anything. It is one bit in a dense array, keyed by entity.index, which is what keeps the common case - an entity which is not part of a hierarchy - on a single cache line. The bit says that the entity had an instance when the bit was set, so an instance which outlived its entity can still answer true for a reused entity id. The instance lookup checks the generation and answers false for that, which is the only case where a write pays the lookup.

A component which has been queued but not executed yet is not in a table, so it cannot be computed. Such an instance is put in the pending set, and ResolvePending() computes it when its components, and the components of its parent, are in a table.
