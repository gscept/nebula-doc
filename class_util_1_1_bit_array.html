Util::BitArray Class Reference

#include <bitarray.h>

Detailed Description

Implements a growable bit array (similar to std::vector<bool>).

Unlike BitField, which is sized at compile time, this grows when a bit outside it is set, which is what makes it usable for a flag per item when the number of items is not known in advance, for example a flag per entity or per instance of a runtime structure.

The storage is one 64 bit word per 64 bits, so a whole section can be skipped with a single word check before any bit is looked at.
