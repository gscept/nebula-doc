◆ RegisterWorld()

void Scripting::ScriptFeatureUnit::RegisterWorld ( Game::World * world)
private

Register a world with the managed mirror.

Native is the source of truth for entities, so a mirrored world is kept in sync by a callback rather than by walking the database.

Sets the entity callback, seeds the queue with the entities that already exist in the world, and remembers the entity count for the next decay sweep.

The walk here only seeds the queue with entities that already existed when the callback was registered, which is the case for entities authored by C++ before the script assembly is loaded, and for worlds that exist before a reload.
