Scripting::PropertyLevelExtension Class Reference

#include <propertyextension.h>

Detailed Description

The level formats' contribution for managed properties.

This is the side that knows what the json means, and the formats only know the extension by name.

The managed entry points are resolved once at registration and cached here, which is what keeps the level format from resolving them through hostfxr for every entity it writes.

The text is the entity as one node per property. It is the only shape the formats can use, because they cannot read the text and cannot group it, and it is the shape an editor command holds as well: a command applies the entity's whole text, which is what makes a change that took a property off read as a change rather than as an addition.

What an editor knows that this side cannot read is handed over as callbacks: the change the managed write path reported, the key a marker was pressed on, and whether a row is the instance's own. These are the editor's half of the contract, and they are null in a build that has no editor.
