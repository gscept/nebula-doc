NavigationFeature::NavigationManager Class Reference

#include <navigationmanager.h>

Detailed Description

Keeps the navmeshes of the level loaded.

A NavMesh component loads its baked navmesh when it is initialized, and releases it when it decays, which also covers a change of its resource in the editor. The loaded navmeshes are registered with the entity they belong to, queries and agents find them by the agent kind they were baked for.

A rebake reloads a navmesh in place, the ids stay valid.
