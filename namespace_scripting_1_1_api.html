◆ EntityHasInstance()

NEBULA_EXPORT bool Scripting::Api::EntityHasInstance ( uint64_t entity)

Whether the entity has an instance.

IsValid only says the id is allocated, and an id can be held by something that has taken the instance out of the world, which is what an editor command does while it waits for a redo. A mirror entity that is only an id has nothing for a component access to read.

◆ InputCharInput()

NEBULA_EXPORT int Scripting::Api::InputCharInput ( char * outBuffer,
int outLen )

The text the keyboard produced during this frame, as utf8 into the buffer C# owns.

Text cannot come back through the marshaler, because a DllImport that returns a string makes the marshaler free the pointer it was given, so this is the only way text crosses. The buffer is terminated, and the answer is the number of bytes written, not counting the terminator.

◆ InputSync()

NEBULA_EXPORT int Scripting::Api::InputSync ( void * buffer,
int bufferSize )

The state is read as it stands when the call is made, which is why the managed side calls this at the beginning of its frame and not anywhere else.

Copy the state of the default keyboard and mouse handlers into the buffer C# owns.

The per-frame flags are cleared at the start of the input frame and set again by the events that arrive during the pump, so a sync before the pump reads the frame that is about to be built, and a sync after EndFrame() reads nothing.

Returns the number of bytes written, or 0 when there is no input server, which is what a build with no window has. The managed side clears its mirror when nothing is written, so a windowless run reads nothing rather than the state the previous frame had.

This has to be in the object library for a managed DllImport to find it, same as the other entry points.

◆ WorldIsSimulating()

NEBULA_EXPORT bool Scripting::Api::WorldIsSimulating ( uint32_t worldId)

Whether the world is simulating.

A world that is not simulating is one the editor is only authoring, and nothing that runs gameplay should run against it

This is the same rule a processor has: a property only runs in a world whose mode is PlayMode, which is what keeps an editor's authoring world from running anything.
