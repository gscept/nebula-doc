Nebula.Game.World Class Reference

Detailed Description

Worlds hold entities.

<remark> Note that the managed side of Nebula Worlds (C# worlds) is basically a mirror of the native side, which has authority. </remark>

void Nebula.Game.World.RefreshMode ( )

Reads the mode from the native world and runs the activation pass when it changed.

This is where a property is activated when its world starts simulating and deactivated when it stops, because a property that was asked to be active only actually runs in a simulating world.
