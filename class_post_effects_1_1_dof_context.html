void PostEffects::DofContext::SetBokeh ( float blades,
float rotation,
float roundness )
static

Aperture.x blade count, y rotation in radians, z roundness in [0, 1].

Blade count 3..8 is a regular iris. Any other count is a disk. Roundness 0 is straight blades, 1 is a disk. w is 0 while the dirt mask is the white placeholder. The mask is rebuilt on the next DofMask dispatch.
