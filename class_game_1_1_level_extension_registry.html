Game::LevelExtensionRegistry Class Reference

#include <levelextension.h>

Detailed Description

The extensions the level formats write and read.

Registered by feature units, which is what keeps the formats from knowing anything about what a feature serializes.

◆ Register()

void Game::LevelExtensionRegistry::Register ( const LevelExtension & extension)
static

register an extension. The name is what the formats use to find it again

An extension is registered by name, and the name is what a file carries, so two extensions cannot share one.

The order they are registered in is the order the formats write them in, which is what keeps a saved level from moving its extension nodes between builds.
