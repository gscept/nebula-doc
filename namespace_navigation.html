The areas a project classifies walkable surface with. The table is written as work/data/tables/navareas.json and compiled to nav:navareas.navareas.

Area 0, "none", is not walkable and area 63, "default", is every surface nothing marks. Both always exist, the table adds areas 1 to 62.

Ties the navmesh builder to the asset formats.

Navmeshes are addressed with URNs of the nav type, folder:file:nav. The work file, work:folder/file.nanav, holds a Navigation::NavMesh description. Baking it writes nav:folder/file.navmesh, a Navigation::BakedNavMesh with the Detour tiles.

A bake is skipped when the export holds the hash of the same inputs: the work file, the area table and the geometry of every source as the geometry loader reads it, so editing a mesh, heightmap or area a navmesh uses bakes it again.

Builds tiled Detour navmesh data from world space geometry.

The builder is format agnostic: it takes geometry which is already loaded, so it can run in the editor, the asset batcher or a test without any resource system. Use the functions in navbuild/geometrysources.h to fill sources from URNs.

Every source carries the world transform it is placed with. Height fields follow the physics height field convention exactly, so the navmesh lies on the collision surface: the origin is the corner of the field, sample (x, z) sits at local (x * sizeX / width, height, z * sizeZ / height) and the height is (sample >> 1) * heightRange / 32767.

The result is always tiled. A tile covers settings.tile_size cells along x and z, tiles without any walkable surface are left out.

Areas are Recast areas: 0 is not walkable, 63 (RC_WALKABLE_AREA) is the default walkable area and anything in between can be assigned with area volumes. Detour polygons keep the Recast area id and get the flags BuildInput::areaFlags lists for it.

Area volumes are applied after the surface is eroded by the agent radius, in the order of their priority, so where volumes overlap the one with the higher priority wins. Convex prisms come from NavArea entities, cylinders are the stamps of painted areas.
