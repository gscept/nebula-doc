◆ PhysicsPending

enum PhysicsFeature::PhysicsPending : uint32_t

what the physics manager has queued for an entity, mixed together in the pending field of the PhysicsActor component.

Adding and removing components is picked up by the component inits and decay callbacks, everything else is pinged by whoever changed the entity

Enumerator
PendingPose 

push the pose of the actor, and the local pose of its shapes

PendingShape 

build or update the shapes of the collider components

PendingBody 

create or update the physx actor of the body component

PendingStructural 

the actor has to look through its shapes for owners which no longer have a component. Only needed when the handle of an entity cannot name the shape it built, because a handle which can name its shape releases that shape itself

PendingAll

◆ GarbageCollectShapes()

void PhysicsFeature::GarbageCollectShapes ( Game::World * world,
Game::Entity bodyEntity,
Physics::ActorId actorId )
static

Releases the shapes of an actor whose collider component is gone, or whose collider entity has been moved to another body.

Shapes that came along with an actor resource are not tracked by the actor and are left alone. This is the fallback for an entity whose handle cannot name the shape it built; an entity whose handle can name it releases that shape by itself, on the decay of its component.

void PhysicsFeature::MarkOwnedShapes ( Game::World * world,
Physics::ActorId actorId )
static

Queues the entities whose shapes hang off an actor which is about to be released, so that their shapes get built again on whichever actor they end up on.

Only shapes built from a collider description are tracked by the actor, and those are the only ones owned by an entity.
