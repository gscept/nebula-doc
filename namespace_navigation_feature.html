NavigationFeature Namespace Reference

Detailed Description

Queries on a loaded navmesh.

Points are found on the surface of a navmesh, paths follow it from one point to another. A navmesh is picked with NavigationFeature::FindNavMesh, by the agent kind it was baked for.

A filter decides which polygons a query may use, and what walking on each area costs. The default filter has the costs of the area table and lets every polygon with a flag through, a polygon of an area without flags is never used.

Every navmesh has one Detour query, the functions run on the game thread only.

◆ MaxSearchesPerUpdate

int NavigationFeature::MaxSearchesPerUpdate = 16
staticconstexpr

how many paths are searched per update.

A target gets its whole path from a full search, the crowd's own queue only runs 100 search iterations per update for all of its agents, which many agents with far away targets wait on for seconds. The searches left wait for the next update, the oldest first
