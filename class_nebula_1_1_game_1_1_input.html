Nebula.Game.Input Class Reference

Detailed Description

The mirror of the engine's default keyboard and mouse handlers.

The engine has authority over the state, and this holds what the last sync saw, so a read is a field read rather than a call through the api.

The mirror is only as good as the frame it was read in. The engine clears the per-frame flags at the start of the input frame and sets them again from the events that arrive during the pump, so the sync has to happen after the pump and before the end of the frame. NebulaApp.OnBeginFrame is that point: the render feature unit pumps the window events at the start of its OnBeginFrame, and the script feature unit is attached after it.

What is here is what the input server received. ImGui gets the keys first and the window drops the events it consumes, so a key typed into a text field never reaches the handlers. HasFocus and the two capture flags are what tell a caller that a key is missing because the UI took it rather than because nobody pressed it.

void Nebula.Game.Input.Sync ( )

Refresh the mirror from the engine.

Called once per frame at the beginning of the frame, after the events have been pumped. A run with no window has no input server, and the mirror is cleared for it rather than left with the state the previous frame had.
