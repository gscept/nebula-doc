IO::ProjectLocator Class Reference

#include <projectlocator.h>

Detailed Description

Resolves the project root and the toolkit (nebula root) directory.

The project info file always lives in the project root. Project identity is therefore a property of where you are.

Resolution order, highest priority first:

  1. an environment variable (NEBULA_PROJECT / NEBULA_TOOLKIT)
  2. walking up from the current working directory looking for the project info file
  3. the value embedded by the build system (NEBULA_PROJECT_ROOT / NEBULA_TOOLKIT_ROOT), which is only needed when the tool is invoked from a build directory that is not inside the project

An explicit command line override outranks all of these, but is handled by the caller, since the locator must not depend on the application layer.
