Nebula.Game.TimeSource Class Reference

Detailed Description

A time source.

The values are the mirror's copy of the native source, refreshed once per frame at the beginning of the frame, so reading them is a field read rather than a call through the api.

A source appears in the mirror after the first sync, and the engine has authority over the time.
